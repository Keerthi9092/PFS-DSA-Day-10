# Day 10 – Doubly Linked List (02-07-2026)

This repository contains my Day 10 practice programs from the Python Full Stack (PFS) Data Structures and Algorithms course. During this session, I learned the fundamentals of Doubly Linked Lists, where each node maintains references to both the previous and the next node. I implemented various insertion, deletion, and traversal operations to understand bidirectional navigation and efficient node manipulation.

## Topics Covered

* Introduction to Doubly Linked List
* Node Structure (Previous and Next Pointers)
* Forward Traversal
* Backward Traversal
* Insertion at Beginning
* Insertion at End
* Deletion at Beginning
* Deletion at End
* Advantages and Disadvantages of Doubly Linked List

## Learning Outcomes

* Understood the structure and working of Doubly Linked Lists.
* Learned how previous and next pointers are maintained during insertion and deletion.
* Implemented forward and backward traversal of the linked list.
* Compared Doubly Linked Lists with Singly Linked Lists.
* Improved understanding of dynamic memory management and bidirectional navigation.
* Strengthened problem-solving skills by implementing Doubly Linked List operations using Python.
